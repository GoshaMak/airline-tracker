\chapter*{\centering ЗАКЛЮЧЕНИЕ}
\addcontentsline{toc}{chapter}{ЗАКЛЮЧЕНИЕ}
%<копируем цель и кратко описываем, что делали и получили в результате; указать, какие задачи выполнили>

Были выполнены все задачи:
\begin{itemize}
	\item выделить основные задачи предметной области;
	\item построить классификацию задач предметной области;
	\item рассмотреть существующие программные решения;
	\item построить сравнительную таблицу для рассмотренных программных решений в соответствии с построенной классификацией.
\end{itemize}

Была достигнута цель научно-исследовательской работы: рассмотрены программные решения для навигации по помещениям для слепых.% В результате исследования было выяснено, что главным критерием качества работы рассмотренных решений является то, на сколько точно определяется местоположение пользователя, так как, если местоположение определяется недостаточно точно, то становится затруднительно координировать действия пользователя.
