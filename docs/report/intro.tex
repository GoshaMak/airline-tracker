\chapter*{\centering ВВЕДЕНИЕ}
\addcontentsline{toc}{chapter}{ВВЕДЕНИЕ}
В современном мире информационные системы играют ключевую роль, так как они упрощают и систематизируют получение информации пользователями.

Авиаперелёты являются неотъемлемой частью современного мира. По данным Росстата~\cite{lit:rosstat} количество человек, пользующихся услугами авиакомпаниий растёт с каждым годом. В связи с этим возрастает спрос на отслеживание авиаперелётов.

\noindent\hspace*{\parindent}Цель курсовой работы --- разработка и реализация информационной системы, прикладные программы которой используют данные, хранящиеся в базе данных, для автоматизации отслеживания полётов авиакомпании.

Задачи курсовой работы:
\begin{itemize}
	\item проектирование и разработка базы данных;
	\item разработка приложения (или приложений) доступа к базе данных.
\end{itemize}
