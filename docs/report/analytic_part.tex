\section{Анализ предметной области}
Авиаперелёты являются неотъемлимой частью современной жизни, в связи с этим появляется спрос на их отслеживание. Предметная область включает в себя отслеживание авиаперелётов. Авиакомпании открывают рейсы, в последствии на которые люди покупают билеты. Для клиентов авиакомпании важно знать будет ли рейс задержан или его перенесли, или вовсе отменили. Отслеживание перелётов подразумевает, что клиенту будет предоставлена информация о том, когда и где будет рейс, а также информация о изменеиях в его расписании.

\section{Формулировка требований к разрабатываемой базе данных и проложению}
База данных должна хранить информацию о пользователях, их отслеживаемых рейсах и о самих рейсах. Приложение должно предоставлять возможность просмотра рейсов и возможность подписаться на него и отписаться от него.

\section{Формализация и описание информации, подлежащей хранению в проектируемой базе данных}
База данных хранит в себе информацию о пользователях, аэропортах, выходах аэропорта, моделях самолётов, самолётах, рейсах и о том какие рейсы интересны пользователю.

Хранимая информация пользователя:
\begin{itemize}
	\item адрес электронной почты;
	\item пароль.
\end{itemize}

Хранимая информация аэропорта:
\begin{itemize}
	\item IATA код --- код используемый для обозначения аэропорта;
	\item название аэропорта;
	\item город, в котором расположен аэропорт;
	\item страна, в которой расположен аэропорт.
\end{itemize}

Хранимая информация выхода аэропорта:
\begin{itemize}
	\item информация об аэропорте, в котором расположен выход;
	\item номер выхода.
\end{itemize}

Хранимая информация модели самолёта:
\begin{itemize}
	\item производитель;
	\item название модели;
	\item масса;
	\item максимальная высота, на которую может подняться самолёт;
	\item максимальная скорость, которую может развить самолёт.
\end{itemize}

Хранимая информация самолёта:
\begin{itemize}
	\item информация о модели самолёта;
	\item регистрационный номер --- уникальный идентификатор, присваиваемый производителем при выпуске;
	\item бортовой номер --- номер, который выдаёт государство, где зарегистрирован самолёт;
	\item сколько миль пролетел самолёт.
\end{itemize}

Хранимая информация рейсе:
\begin{itemize}
	\item самолёт, который выполняет рейс;
	\item дата запланированного вылета;
	\item дата запланированного прилёта;
	\item дата вылета;
	\item дата прилёта;
	\item статус;
	\item план рейса.
\end{itemize}

Хранимая информация рейсах интересных пользователю:
\begin{itemize}
	\item информация о пользователе;
	\item информация о рейсе.
%	\item информация за сколько прислать уведомление.
\end{itemize}

Пользователи приложения: администратор, пользователь и авторизованный пользователь. Администратор управляет информацией о полётах. Все пользователи могут просматривать информацию о рейсах, а авторизованный пользователь может отслеживать информацию о конкретном рейсе.
