# HTTP-сценарий и захват трафика

Из корня репозитория:

```sh
make test-traffic RUN_ID=demo
```

Команда поднимает отдельный тестовый стенд и запускает [scenario.sh](scenario.sh).
Скрипт отправляет запросы через `curl`, проверяет ответы через `jq` и одновременно
записывает HTTP-трафик через `tcpdump`.

| Шаг | Запрос | Ожидаемый результат |
|---|---|---|
| Регистрация пассажира | `POST /api/v1/users` | `201` |
| Вход пассажира | `POST /api/v1/auth/tokens` | `200`, JWT |
| Просмотр рейсов | `GET /api/v1/flights?limit=10` | Исходный рейс в статусе `scheduled` |
| Подписка | `POST /api/v1/subscriptions` | `200` |
| Проверка подписки | `GET /api/v1/subscriptions` | Один выбранный рейс |
| Вход администратора | `POST /api/v1/auth/tokens` | `200`, JWT администратора |
| Изменение рейса | `PATCH /api/v1/flights/{id}` | `delayed` и уникальная метка в плане |
| Проверка изменения | `GET /api/v1/flights/{id}` | Обновлённые статус и план |
| Проверка письма | `GET /api/v1/messages`, `GET /api/v1/message/{id}` в Mailpit | Письмо нужному пассажиру с меткой и изменённым статусом |

В стенде уже есть администратор `admin@airline.test` / `TestAdmin123!`, созданный
фикстурой `tests/environment/sql/seed.sql`. Служебная команда основного приложения
для этого сценария не требуется. Пассажир и метка плана создаются заново при каждом запуске.
Ожидание письма ограничено 30 секундами.

Результаты находятся в `tests/environment/results/demo/traffic/`:

- `http.pcap` -- захват HTTP-запросов и ответов;
- `http.txt` -- текстовая расшифровка `tcpdump -nn -A -r http.pcap`;
- `tcpdump.log` -- статистика захвата;
- `response.json` -- последний ответ для диагностики.

Захват содержит тестовые пароли и JWT изолированного стенда.
После сценария, включая ошибку, существующий механизм очистки восстанавливает БД,
вычитывает Kafka и очищает Redis и Mailpit. Приложение остаётся остановленным;
результаты сохраняются. Повторный запуск с тем же RUN_ID выполняет сценарий заново
и перезаписывает захват. Удаление стенда:

```sh
make test-env-down RUN_ID=demo
```
